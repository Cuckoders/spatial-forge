# Spatial Forge

Локальный браузерный 3D-планировщик квартир, домов и земельных участков. Работает как визуальный редактор: добавляйте прямоугольные и треугольные блоки на сетку, настраивайте стены, переключайте этажи и размещайте свои модели.

## Возможности

- интерактивная 3D-сцена с вращением, панорамированием и масштабированием;
- прямоугольные и треугольные помещения с привязкой к сетке 0,5 м;
- точная настройка положения, размеров, высоты и толщины стен;
- отдельное редактирование каждой грани стены;
- дверные и оконные проёмы с настройкой положения, ширины, высоты и подоконника;
- загрузка текстур PNG, JPEG и WebP и применение к выбранной стене;
- несколько этажей, режим активного этажа и общий вид;
- встроенная библиотека мебели и деревьев;
- загрузка собственных самодостаточных моделей GLB 2.0;
- режим квартиры и режим земельного участка;
- виды камеры: перспектива, сверху и спереди;
- локальное автосохранение и импорт/экспорт проекта в `.spatial.json`.
- перемещение выбранных комнат и объектов 3D-манипулятором;
- история последних 60 изменений с отменой и повтором.

## Запуск

Требуется Node.js 22+.

```bash
npm install
npm run dev
```

Проверка и production-сборка:

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
```

## Управление

- левая кнопка мыши — выбор элемента или вращение камеры;
- правая кнопка — панорамирование;
- колесо — масштаб;
- `V`, `R`, `T` — выбор, прямоугольник, треугольник;
- `Delete` — удалить выбранный элемент;
- `]` — повернуть выбранный блок или объект на 15°;
- `1`, `2`, `3` — переключить вид камеры;
- `Escape` — снять выделение.
- `Ctrl/Cmd + Z` — отменить, `Ctrl/Cmd + Shift + Z` — повторить.

## Форматы и приватность

Spatial Forge не отправляет планировки и пользовательские файлы на сервер. Геометрия, цвета и встроенные объекты сохраняются в `localStorage`. Загруженные текстуры и GLB-модели остаются только в текущей вкладке и после перезагрузки их нужно выбрать снова.

Ограничения импорта:

- проект JSON — до 2 МБ;
- текстура PNG/JPEG/WebP — до 8 МБ и 8192×8192;
- модель — самодостаточная GLB 2.0 без внешних URI, до 25 МБ;
- до 12 этажей, 500 геометрических блоков и 200 объектов.
